# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/AdamSiekierski/wtclean/security/advisories/new).
You should get a reply within a week.

Things that count: a way to make wtclean delete something it should not (the main checkout,
a dirty or unmerged worktree, a remote branch), or to leak the GitHub token it uses.
